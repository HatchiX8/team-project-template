# 版本與發布規範

> 狀態：草稿

用於對齊團隊的版本標示與發布方式，讓成員能辨識版本及其對應變更。

## 適用範圍

團隊各專案的版本號、升版、Git tag 與發布資訊。

## 版本規則草案

以下內容移植自 LINE 售服系統部署文件，作為團隊跨專案規範的討論起點，尚未經團隊核准。

### 版本格式

- 版本使用日期格式 `vYYYY.MM.DD`，例如 `v2026.10.06`。
- 同一天第二次發布起加上序號，例如 `v2026.10.06.2`。

### Git Tag

- 版本 tag 只能建立在 `main`。

在 `main` 建立版本 tag 並推送，以下指令以 `v2026.10.06` 示範：

```powershell
git tag v2026.10.06
git push origin v2026.10.06
```

範例中的版本號須替換為本次要發布的版本；本文件不取代各專案的部署流程。
