# 團隊工程規範

> 狀態：草稿

此目錄集中放置跨專案沿用的團隊工程規範，主要供工程師與新進人員閱讀、討論及檢視團隊約定。

## 適用範圍

- 團隊跨專案共用的協作方式與工程約定。
- 專案專屬需求、技術選型、架構與環境設定放在 `docs/project/`。
- Agent 角色流程放在 `project-agent/`。

Agent 的實際操作準則會直接寫入角色 Workflow，不以本目錄作為每次任務的必讀入口；必要時可透過引用追查約定的背景與說明。

## 文件索引與建議閱讀順序

以下為新進人員與團隊成員的建議導讀順序：

1. [Agent 操作範圍](agent-operations.md)：先理解單模組開發、跨模組修改的分階段協作與工程師確認點。
2. [團隊命名規範](naming.md)：了解資料夾、檔案、Type、Schema 與程式碼命名，以及固定用途名稱豁免。
3. [Git 協作規範](git-workflow.md)：了解分支、commit、PR、審查與合併約定。
4. [版本與發布規範](versioning.md)：了解版本號、tag 與發布約定。
