# LINE 售服系統專案文件（討論稿）

> 本目錄供團隊對焦 LINE 售服系統的目標、需求與技術方向，示範專案文件可能的寫法。所有內容均為未核准初稿，不作為開發、驗收或部署的正式依據。

## 適用範圍

本目錄只涵蓋 LINE 售服系統的初期專案討論；不修改 monorepo 共用規範，也不取代後續模組文件與 API Contract。

## 文件導覽

| 文件 | 用途 |
|---|---|
| [專案概覽](./overview.md) | 對齊目標、使用者、主要情境與專案邊界 |
| [架構初稿](./architecture.md) | 描述系統組成、現有 monorepo 基礎與尚待確認的技術決策 |

## 閱讀與使用方式

- 「評估報告提出」表示來源中的方案或估算，不代表團隊已核准。
- 「目前方向」表示後續會議或現有 repository 提供的較新脈絡，仍需團隊確認是否適用於本專案。
- 「待確認」表示不得據此直接實作或作為驗收條件。
- 團隊討論並核准後，再依專案文件流程更新正式依據、拆分模組文件與 API Contract。
