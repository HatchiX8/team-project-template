# 前端技術規則

- 依已核准的前端架構與既有模組模式，區分頁面組裝、功能邏輯、資料存取、狀態與呈現；不得為套用通用分層而重構既有程式。
- 共用 UI 元件不應耦合單一功能的業務規則；新增共用元件前確認確有跨功能用途。
- API 呼叫、資料轉換與畫面狀態應沿用現有責任分配，不讓呈現元件承擔難以追蹤的副作用。
- 新增狀態前確認其使用範圍；局部狀態不因方便而升為全域狀態，不繞過既有 store／action 資料流。
- 修改 UI 時沿用已採用的樣式、元件與設計規範；不為單一需求引入另一套 UI 或 CSS 工具。
