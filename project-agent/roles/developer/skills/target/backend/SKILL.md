# 後端技術規則

- 依已核准的模組與 API 依據，維持 HTTP 邊界、業務流程、資料存取與外部服務的責任可辨識；不因本 Skill 強制新增尚未採用的分層。
- API 輸入與輸出以對應 Contract 為準；不得直接將未驗證輸入用於資料寫入或權限判斷，也不得意外暴露內部資料或例外內容。
- 調整多步驟寫入、交易、排程或外部副作用時，確認既有順序、失敗傳遞與部分完成狀態，未經任務要求不改變交易邊界。
- 修改資料查詢時沿用專案既有資料存取方式，避免未驗證輸入拼接查詢或造成明顯不必要的重複查詢。
- 改變 API、資料結構、權限或跨模組介面前，依 Developer 一般開發流程確認正式依據與使用端；Skill 不提供額外修改授權。
