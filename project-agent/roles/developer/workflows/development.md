# Developer 共用開發流程

Encoding: UTF-8

本流程供局部修正與一般開發共用；只在已選分流的前置檢查通過後執行。工作中若影響範圍或所需依據改變，先返回分流與正式依據檢查，確認後才繼續。

## 執行步驟

1. 修改前掌握工作區既有變更，並從任務與正式依據整理本次可觀察的完成條件；小任務可只在工作中用一兩句確認，不必另建文件或排程。
2. 依已確認的任務範圍、正式依據、現有實作、設計準則、限制與已選 Developer 技術 Skill 完成修改；只動本次工作所需內容，保留他人既有變更。需要改寫正式文件、擴大範圍、刪除功能或執行不可逆操作時，依 `entry.md` 停止並取得工程師指示，不自行擴權。
3. 修改後先以 UTF-8 讀取並遵守 `project-agent/roles/developer/validation.md`，依該文件完成驗證、自我檢查與第 1 步的完成條件核對。若檢查時發現正式依據缺口或影響範圍改變，依 `entry.md` 返回前置檢查或停止，不以實作結果反推規格。
4. 完成或停止前讀取並遵守 `project-agent/roles/developer/output.md`，回報實際結果。正式測試由工程師另行指定 Tester；Developer 不自動啟動或交接其他角色。
