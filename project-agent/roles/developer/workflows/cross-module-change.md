# Developer 跨模組修改階段流程

Encoding: UTF-8

本流程只供既有內容修改使用；涉及多個業務模組或需明確安排階段的共用內容時載入。它補充共用開發流程的階段控制，不新增第三條開發分流，也不放行跨模組新增開發。

## 階段規劃

- 依任務、正式依據、程式碼與相關引用確認要修改的業務模組、共用檔案及受影響使用端。
- 階段數依實際修改單位安排，不直接等同受影響業務模組數；只受影響但無須修改的使用端不另立修改階段。
- 每個模組階段只修改一個業務模組，不合併多個模組。
- 已確認的共用檔案可以明確歸入某一模組階段，或安排獨立的共用內容階段。
- 計畫須列出共用檔案路徑、歸屬階段、受影響使用端與驗證方式，取得工程師明確確認後才可修改。
- 獨立共用階段只修改明列的共用檔案；歸入模組階段時，也不代表該共用檔案成為該模組專屬內容。
- 其他模組的使用端若需要配合修改，仍安排各自的模組階段，不藉共用階段一併修改。
- 同一模組的 Web 與 Server 放在同一階段。
- 依相依關係安排順序，列出各階段修改範圍、完成條件與驗證方式。
- 規劃不另建文件；依 `output.md` 在對話中說明並取得工程師明確確認後，才開始第一階段。
- 模組歸屬、共用能力範圍或階段順序無法確認時，回報問題並等待工程師決定，不自行補成已核准範圍。

## 執行當前階段

- 確認當前階段編號、修改單位、明列的檔案範圍與已確認的整體任務範圍。
- 記錄當前相關檔案狀態，區分他人既有變更、已完成階段與本階段修改。
- 完成當前分流的必要前置檢查，依 `skill-selection.md` 選取並讀取適用的技術 Skill。
- 理解當前模組或共用內容及其使用端的必要正式依據；規劃時已讀文件不免除恢復後的重新核對。
- 依 `development.md` 完成當前階段的實作、驗證與回報，不重複執行第二套開發流程。
- 只能修改當前階段明列的模組範圍與已確認共用檔案；未列入當前階段的模組或共用內容僅可唯讀確認。

## 暫停與下一階段

- 每階段驗證後依 `output.md` 回報，請工程師檢視本階段 diff 是否限於明列的模組與共用檔案範圍。
- 有後續階段時，停止本輪修改並等待工程師明確確認本階段結果、指示進入下一階段。
- 確認可透過訊息或工具提供的操作完成，不假設一定有確認按鈕。
- 未回覆、檔案更新、先前同意整體計畫或含糊回應，不代表本階段已確認。
- 恢復時重新讀取專案入口與 Developer 角色規則，依 `entry.md` 判斷並輸出提示，不重複輸出。
  - 本則訊息明確指定 Developer 時，輸出進入提示。
  - 未指定角色且符合 Developer 任務延續條件時，輸出延續提示。
- 重新指定角色只改變本則的提示判斷；確認仍為原任務後，接續既有階段計畫與成果，不重啟第一階段。
- 核對階段計畫、已完成成果、工程師回饋與待解除阻礙後，才進入原計畫內的下一階段。
- 工程師要求修正當前階段時，先完成該階段修正並重新驗證、回報，不同時修改下一階段的內容。

## 相依阻礙與範圍變動

- 需要修改其他模組才能解除驗證失敗時，指出失敗項目、相依模組、證據與原因，不提前修改其他模組。
- 尚未完成的跨模組介面調整造成失敗時，須由工程師明確允許帶著該阻礙進入下一階段。
- 來源尚未確認時，如實回報，不逕稱已知相依阻礙。
- 必要正式依據缺失、未核准、矛盾或規則牴觸時，仍依 `entry.md` 停止；階段確認不能取代文件核准或解除規則衝突。
- 新增原計畫外模組、共用能力或專案設定時，停止受影響修改，說明原範圍、新增影響與計畫差異。
  - 依根目錄 `AGENTS.md` 與 `entry.md`，請工程師在新訊息重新指定 `角色：developer` 並確認擴大範圍。
  - 更新階段計畫並取得確認後，才執行新增範圍，不將補讀文件或 Skill 視為修改授權。
- 任務若涉及其他模組的新增開發，請工程師另立單模組開發任務，不套用本流程。

## 最終驗證與完成

- 最後階段依 `validation.md` 完成必要整合驗證，重新核對已記錄的相依阻礙與整體完成條件。
- 整合驗證不能藉機跨階段修正；需要修正已完成的模組或共用內容時，先回報並取得工程師確認，更新階段安排後依修改單位逐階段修正。
- 僅在整體完成條件已核對且必要失敗已處理後，依 `output.md` 回報整體結果；未驗證項目仍須明列，不宣稱通過。

## 階段安排範例

- 案件與客戶模組都需配合修改共用型別時，可安排「共用型別 → 案件 → 客戶」三個階段。
- 工程師也可明確同意將該共用型別歸入案件階段，安排「案件與指定共用型別 → 客戶」兩個階段。
- 兩種安排都須列明共用檔案與使用端；每階段驗證後仍停下等待確認，不提前修改下一階段。
