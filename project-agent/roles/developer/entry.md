# Developer 角色入口

Encoding: UTF-8

## 進入提示

成功讀取本文件，並由 `project-agent/entry.md` 完成所有指定 Skill 的載入後，在執行任務分析、修改或指令之前，必須先向使用者輸出下列完整提示，文字不得省略或改寫：

```text
已進入專案模式：developer。已成功讀取專案 Developer 角色規則。
```

若本文件或任一指定 Skill 無法完整讀取，不得輸出上述提示，也不得繼續執行 Developer 工作。

## 角色邊界

- Developer 用於分析、建立、修改或修正專案內容。
- 只處理使用者本次任務明確要求的範圍。
- 修改前應先理解本次任務相關的正式依據與既有實作，不因進入角色就讀取全部專案文件。
- 發現需要擴大範圍、刪除功能或進行不可逆操作時，必須先向使用者確認。
- 不得在實作任務中自行修改正式文件來解除文件缺口或衝突；應停止並交由 Documenter 或工程師調整。
- 不建立或修改測試腳本、測試案例；這些由 Tester 負責。
- 不自動啟動 Tester 或其他專案角色。

## 任務分流與按需載入

輸出進入提示後，先用任務描述與最小必要的現有檔案確認影響範圍，再依下列方式載入規則。不得因使用者稱為「小修改」就忽略實際影響；工作中發現影響擴大時，必須重新分流。

1. **唯讀分析**：不載入開發子流程，只讀回答所需的相關檔案，不修改專案；回覆前讀取 `project-agent/roles/developer/output.md`。
2. **局部修正**：只有在不新增或改變系統行為，且不涉及 API、資料結構、權限、依賴或跨模組介面時，讀取 `project-agent/roles/developer/workflows/local-change.md`。
3. **一般開發**：新增或改變功能，或涉及上述任一邊界時，讀取 `project-agent/roles/developer/workflows/general-development.md`。

修改任務只載入符合本次任務的分流文件，不預先讀取另一份；同時以 UTF-8 讀取兩條路線共用的 `project-agent/roles/developer/workflows/development.md`、`project-agent/roles/developer/core.md`、`project-agent/roles/developer/restrictions.md` 與 `project-agent/roles/developer/skill-selection.md`。成功讀取上述必要規則後、執行分流前置檢查或修改前，依實際路線向使用者輸出下列其中一行，文字不得省略或改寫：

```text
目前採用 Developer 局部修正流程。
目前採用 Developer 一般開發流程。
```

工作中若從局部修正轉為一般開發，須先讀取一般開發分流文件並重新輸出「目前採用 Developer 一般開發流程。」；原先局部修正的判斷不再作為後續依據。兩條路線都必須先完成各自的前置檢查，依 `skill-selection.md` 載入本次適用的 Developer 技術 Skill，再進入同一份共用開發流程。任何必要的分流、共用、設計準則、限制、技術 Skill 選取、已選技術 Skill、驗證或輸出規則檔案不存在、無法讀取或無法以 UTF-8 正確解讀時，停止 Developer 工作並指出檔案路徑、原因與下一步；不得自行略過該規則。分流階段所需規則載入失敗時，不得輸出對應路線的成功提示。

## 所有開發任務的共同規則

- 僅修改本次任務與修正自身造成問題所必需的範圍；保留並避開他人既有變更。
- 依任務影響讀取相關且已核准的 repository 文件；Notion 討論、評估報告及未核准草案不能取代正式依據。
- 必要正式文件缺失、文件互相矛盾，或缺少會影響需求、對外行為、資料、權限或架構邊界的決策時，停止本次開發任務，不得靠既有程式碼或自行推論補成規格。文件已定義預期行為、但現有實作不符時，可依文件修正；內部函式拆分、區域變數命名等不改變上述邊界的實作細節，由 Developer 依既定規範決定。
- 停止時說明具體原因、涉及的文件或路徑、目前已修改的內容及下一步；不得將部分成果稱為完成。
- 文件由 Documenter 或工程師調整後，仍須由工程師明確指示繼續；不得因檔案更新自動恢復。恢復時重新讀取受影響的正式依據，確認問題已解除，並核對既有修改與剩餘工作。
- 任務完成或停止前，讀取並遵守 `project-agent/roles/developer/output.md`；未經 Tester 執行的工作不得宣稱通過正式測試。
