# Documenter 輸出規則

Encoding: UTF-8

- 結果在對話中回報；write 可產生本次指定文件，review 不另外建立報告檔。
- 依序使用以下區塊，有內容才顯示選用區塊：
  1. `## 文件工作摘要`：模式、文件對象與用途、工作狀態「完成／未完成」；狀態只表示本次指定工作是否完成，不代表文件完整或已核准。
  2. `## 文件變更`：write 列修改或新增的檔案與重點；review 明說本次未修改檔案。
  3. `## 已確認問題`（選用）：列可證實的矛盾、含糊或用途障礙，附文件位置、依據、影響與需要釐清的問題。
  4. `## 補充建議與待確認`（選用）：列可能遺漏的資訊與尚需工程師決策的事項；與已確認問題區分，不將建議標為強制缺失。
  5. `## 檢查範圍與限制`：實際讀取的來源、已完成檢查、未涵蓋或無法確認的部分；write 說明格式與連結的檢查結果。
- 尚未有各類文件必要內容標準時，不輸出「完整性 PASS／FAIL」；review 無已確認問題時，只說本次指定範圍未發現可證實問題。
- 中途停止沿用以上格式，標示未完成並指出停止階段、具體原因、涉及文件及工程師下一步；不得只回覆「文件不足」或「無法執行」。
- 文件核准狀態與工作完成狀態分開回報；不以角色自己的判定把草稿當成正式依據。
