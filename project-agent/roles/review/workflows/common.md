# Review 共用規則

Encoding: UTF-8

本文件由 Review 角色入口在確認 `feature` 或 `module` 模式後、載入對應分支前讀取。

- 兩種模式均須遵守本文件。
- 本文件不自行決定檢查範圍，也不取代分支檢查流程。

## 證據與結論

- 通過或問題判定須以本次實際讀取、可指出位置的文件、實作、變更或測試證據為依據。
- 尚未檢查、證據缺失或無法讀取的事項須標示「未驗證」，不得推測為已通過。
- 分支流程未完成時，不得宣稱 Review 完成。

## 共通風險檢查

- 兩種模式都須在各自確認的範圍內，按實際資料流、互動與外部整合檢查適用項目；沒有相關情境時不強行套用，也不得以本清單補造正式需求。
- 發現問題仍須依分支的 `review.md` 核對影響、證據與嚴重度。

- **非同步與資料新鮮度**：檢查並行請求、非同步回應、狀態更新或快取是否可能產生競爭、過期資料覆蓋新結果，或讓直接使用端看到不一致狀態。
- **重複操作與副作用**：有重複送出、重試或重入情境時，檢查是否可能重複寫入、重複觸發外部副作用，或在部分步驟失敗後留下未處理的不一致狀態；不要求所有操作一律採用相同的冪等設計。
- **敏感資訊**：檢查受影響流程是否將密鑰、token、credential 或其他敏感資料輸出到 log、錯誤訊息、API 回應或瀏覽器可取得的內容。
