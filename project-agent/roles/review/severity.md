# Review 嚴重度與通過判定

Encoding: UTF-8

本文件在範圍解析成功後與檢查流程一併載入，用於標示發現項目與總結判定。

## 嚴重度

- **Blocker**：必須處理才能合併或接受。例如錯誤行為、權限或資料風險、與已核准 Contract／正式依據明顯衝突且無依據支持。
- **Major**：高回歸風險、缺關鍵測試／CI 證據、重要正式依據不一致。
- **Minor**：可接受但建議修改。
- **Note**：資訊或風格提醒，不影響總結判定。

## 通過判定

- 存在任一 **Blocker** → **需修改**。不得將結果表述為可合併或已通過。
- 無 Blocker，但有 **Major**，或存在會影響合併判斷的關鍵「無法驗證」→ **有條件／需補證**。須明確寫出缺什麼或需補哪些證據。
- 僅有 **Minor**／**Note**，或無發現項目 → **可接受**。仍應列出已發現的 Minor／Note；沒有項目時不建立空泛區塊。

無法驗證的項目不計入「已通過」；若該項會影響合併判斷，依上列規則反映在總結判定中。
