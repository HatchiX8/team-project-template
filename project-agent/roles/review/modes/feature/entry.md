# Review feature 模式入口

Encoding: UTF-8

本入口只在 `project-agent/roles/review/entry.md` 已確認 `模式：feature`、單一功能及其所屬模組，並載入 `workflows/common.md` 後執行。

- 維持 Review 唯讀邊界；不重新判斷模式或啟動其他角色。
- 本模式只判定指定功能及直接關聯範圍，不宣稱整個模組已通過 Review。

## 規則載入

- 開始檢查前，以 UTF-8 讀取本資料夾的 `scope.md`、`skill-selection.md`、`review.md` 與 `output.md`。
- 確認上述規則與已載入的共用規則及彼此沒有不可消解的牴觸。
- 任一必要規則不存在、無法讀取或仍是 TODO 時，指出實際路徑與原因後停止；不得略過或自行補造。
- 停止時若 `output.md` 可讀，依其停止格式回報；否則依本入口與共用入口的失敗處理回報。

## 執行順序

1. **確認範圍**：依 `scope.md` 定位功能、所屬模組、正式需求、API 依據、實作及直接關聯使用端；必要依據缺失、矛盾或功能無法唯一定位時停止。
2. **選取技術準則**：依 `skill-selection.md` 選取並讀取本次實際涉及的 Developer 技術 Skill，僅作 Review 的技術檢查參考。
3. **執行檢查**：依 `review.md` 核對該功能的需求、實作、直接影響與既有證據；不建立或執行測試，也不修改專案。
4. **回報結果**：依 `output.md` 回報結果或停止原因；不建立報告檔，不將未完成工作稱為通過。

- 發現新的直接關聯使用端或技術時，先依 `scope.md` 重查邊界，再依 `skill-selection.md` 補讀必要參考文件，之後才檢查新範圍。
- 若必須全面檢查整個模組或另一項獨立功能，停止擴大部分並請使用者另行指定 Review 模式與對象。
